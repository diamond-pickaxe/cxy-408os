# 宇的大观本地版

用于个人学习的 408 真题离线刷题系统。题库、题目图片、答案、解析和公式字体均保存在本机，使用时不需要登录原站。

## 打开方式

从 Release 下载 `yu-daguan-local-v1.0.0.zip`，解压后双击 **宇的大观本地版.html** 即可使用。

Windows 也可以双击 **启动宇的大观本地版.cmd**：已安装 Node.js 时在固定本机地址 `http://127.0.0.1:4188` 打开；没有 Node.js 时直接打开 HTML。

建议固定使用同一个浏览器和打开方式。切换浏览器、电脑或打开方式之前，先导出学习记录，再在新环境导入。

## 功能

- 2009—2026 年，共 18 套试卷、846 道题，包含选择题和非选择题。
- 科目、章、小节三级知识目录，选择范围后自动高亮对应题目。
- 点击“开刷”列出当前筛选内全部题目，可以连续向下刷题。
- 点击年份直接进入该年完整试卷，支持在试卷内切换选择题与非选择题。
- 答案解析、掌握标记、笔记、收藏夹、薄弱题复习和本地学习历史。
- 学习记录自动保存到当前浏览器，支持导出与导入 JSON 备份。
- 桌面常驻知识目录和顶部导航，小屏使用知识目录抽屉和底部导航。

## 学习记录

发布版本不预置任何人的掌握状态、笔记、收藏或答题记录。可以导入自己的备份，也可以直接开始练习。已有离线记录优先使用浏览器中保存的数据，升级不会覆盖现有进度。

离线版记录在本机发生的学习操作。原站账号和云端学习历史不会自动同步到本项目。

源码与 Release 均不包含本机个人记录。构建时会生成空白初始进度，个人备份文件和 `.private/` 不参与提交。题库和解析属于第三方素材，仓库按个人使用目的保持私有；进一步分享前应确认相关授权。

## 开发与验证

需要 Node.js 20 或以上版本。应用本身没有必须在线安装的运行依赖，开发测试依赖可通过以下方式安装：

```sh
npm ci
npm run check
npm run package
npm start
```

`npm run check` 检查筛选、整卷模式、题型筛选、答题记录持久化与备份恢复，并验证 846 道题的离线资源和发布包不含个人记录。`npm run package` 生成单文件 HTML、便携 ZIP 和校验文件。

主要文件：`app.js` 为练习逻辑，`app.css` 为界面，`data.js` 为题库，`seed.js` 为空白初始进度。`build.mjs` 打包为独立 HTML，`tests/` 包含行为回归测试。
